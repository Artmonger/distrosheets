HSTS Enablement Documentation

App: Easy Image Resizer
Domain: https://imageresizer.filesmarter.com

What is HSTS?

HTTP Strict Transport Security (HSTS) is a web security policy mechanism that helps protect websites against man-in-the-middle attacks by enforcing the use of HTTPS.

How HSTS is Enabled

HSTS is enabled for all responses using the helmet middleware in the app's server.js file:

const helmet = require('helmet');

// ... other middleware and setup ...

// Enable HSTS for all responses
app.use(helmet.hsts({
  maxAge: 31536000, // 1 year in seconds
  includeSubDomains: true,
  preload: true
}));
  • max-age=31536000: Browsers will only access the site over HTTPS for 1 year.
  • includeSubDomains: Applies the rule to all subdomains.
  • preload: Indicates intent to be included in browser HSTS preload lists.

How to Verify

You can check the response headers from the app using browser dev tools or curl:

curl -I https://imageresizer.filesmarter.com/

The response will include:

Strict-Transport-Security: max-age=31536000; includeSubDomains; preload

Summary

This app is fully HSTS-compliant and enforces HTTPS for all users and subdomains for at least one year.
