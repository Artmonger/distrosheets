Installation Guide

1. Setting Up Your Board

Open your Monday.com board where you want to use the image resizer.
Add two file columns to your board:
  • One for original images (source)
  • One for resized images (target)
Note: The app requires two separate file columns to work properly - one for input and one for output.

2. Adding the App to Your Board

Click the "+" button in the top menu bar of your board
Select "Add apps" from the dropdown menu
Search for "Easy Image Resizer" in the apps marketplace
Click "Install" and authorize the app

3. Using the App

Open any item in your board by clicking on it
Click the "..." menu in the top-right of the item view
Select "Easy Image Resizer" from the apps menu
The app will open in the item view, ready to process your images

4. Supported File Types

The following image formats are supported:

JPEG (.jpg, .jpeg)
PNG (.png)
WebP (.webp)
GIF (.gif)
BMP (.bmp)
TIFF (.tiff)
PSD (.psd)
SVG (.svg)
Important: For best results, use JPEG or PNG files. The app will maintain high quality settings (95% quality for JPEG, lossless for PNG).

5. Image Processing Options

Square Mode

  • Crop to Square: Centers and crops the image to create a perfect square
  • Add Padding: Adds white or transparent padding to create a square without cropping

Custom Mode

  • Custom Dimensions: Specify any width and height for your output image
  • Smart Cropping: Automatically focuses on the important parts of the image

6. Tips for Best Results

  • Use high-quality source images for better output
  • For transparent backgrounds, use PNG format
  • Maximum dimension size is 5000 pixels
  • Minimum dimension size is 1 pixel
  • The app maintains aspect ratio when possible to prevent distortion

7. Troubleshooting

Common Issues:

  • File Not Showing: Make sure you've uploaded an image to the source column
  • Processing Failed: Check if your file format is supported
  • App Not Loading: Refresh the page or check your internet connection
