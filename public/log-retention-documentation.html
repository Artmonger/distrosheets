App: Easy Image Resizer

Log Retention Policy

User logs are retained for up to 2 months (60 days) in accordance with security and compliance requirements.

How Log Retention is Configured

Log retention is managed using the winston logger with winston-daily-rotate-file in the app's server.js file:

const logger = winston.createLogger({
  level: 'info',
  format: winston.format.combine(
    winston.format.timestamp(),
    winston.format.json()
  ),
  transports: [
    new winston.transports.DailyRotateFile({
      filename: 'logs/user-%DATE%.log',
      datePattern: 'YYYY-MM-DD',
      maxFiles: '60d', // Logs are kept for 60 days (2 months)
      maxSize: '20m'
    })
  ]
});
  • maxFiles: '60d': Logs are retained for 60 days (2 months) before being deleted.
  • Logs are rotated daily and stored in the logs/ directory.

How to Verify

You can verify log retention by inspecting the server.js configuration and the logs/ directory on the server.
