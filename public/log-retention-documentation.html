Log Retention Documentation

App: Easy Image Resizer (image-resizer-app-2024)
Log Storage: Amazon S3
Bucket: mondayimageresizer
Region: us-east-2 (Ohio)

How Logs Are Uploaded

  • A script (heroku-fetch-logs.js) runs daily via Heroku Scheduler.
  • The script fetches the latest logs from the Heroku app and uploads them to the S3 bucket under the logs/ prefix.
  • Each log file is named with the date, e.g., heroku-log-YYYY-MM-DD.log.

How Log Retention is Enforced

  • S3 Lifecycle Rule: An S3 lifecycle rule is configured on the bucket to automatically delete log files in the logs/ folder that are older than 60 days (2 months).
  • This ensures that no logs older than 2 months are retained, meeting compliance and security requirements.

How to Verify

  1. Check S3 Bucket: Go to the AWS S3 console, navigate to the mondayimageresizer bucket and the logs/ folder. You will see daily log files, each named by date.
  2. Check Lifecycle Rules: In the S3 bucket, go to the Management tab. Under Lifecycle rules, you should see a rule that expires (deletes) objects in logs/ after 60 days.

Sample S3 Lifecycle Rule JSON

{
  "Rules": [
    {
      "ID": "DeleteOldLogs",
      "Prefix": "logs/",
      "Status": "Enabled",
      "Expiration": {
        "Days": 60
      }
    }
  ]
}

Proof of Retention

  • Daily uploads are visible in the S3 bucket under logs/.
  • Automatic deletion of logs older than 60 days is handled by the S3 lifecycle rule.
  • This setup ensures logs are retained for up to two months, with no manual intervention required.
