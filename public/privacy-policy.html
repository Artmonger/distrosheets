Privacy Policy

This privacy policy describes how the Monday Image Resizer app ("we", "our", or "the app") handles information when you use our service through Monday.com.

Data Collection and Usage

The Monday Image Resizer app is designed with privacy in mind and operates on a no-storage principle:

  • We do not collect or store any personal information
  • We do not maintain any databases
  • We do not track usage patterns
  • We do not use cookies

Image Processing

When you use our app to resize images:

  • Images are processed entirely in memory
  • No temporary files are stored on our servers
  • Original and processed images exist only in your Monday.com workspace
  • All processing is done in real-time and immediately discarded

Monday.com Integration

This app integrates with Monday.com using their official API and requires the following permissions:

  • boards:read - To access your board structure and column information
  • boards:write - To save processed images to your chosen columns
  • files:read - To access your source images
  • files:write - To save processed images
  • context:read - To understand which board/item is being accessed
  • context:write - To update the current context when needed

Data Security

We prioritize the security of your data:

  • All communication is encrypted using HTTPS
  • We use Monday.com's secure authentication methods
  • No data persists beyond the immediate processing request
  • The app runs on Heroku's secure infrastructure

Third-Party Services

This app only communicates with the Monday.com API and the Heroku platform (for hosting).

  • Monday.com API (api.monday.com): Used for authentication, board/item data, and file operations as part of core app functionality.
  • Heroku (herokuapp.com): Used for hosting the app frontend and backend.

We do not use any third-party analytics, advertising, or tracking services. No user data is shared with or sent to any other external domains or products.
